# repo 0.2.0 — 빠른 시작 (Windows Portable)

## 처음 시작하기
1. `Ctrl+N`으로 작품 폴더를 선택하거나 생성합니다.
2. 화면 위 작품 제목을 입력합니다. `Ctrl+T`로 언제든 수정할 수 있습니다.
3. 중앙에서 원고를 작성하고 왼쪽 오브젝트 목록, 오른쪽 등장 정보 패널을 봅니다.
4. `F1`으로 앱 안에서 도움말을 엽니다.

## 원고 예제
```text
# 병원 복도 - 밤

## 형광등이 깜빡인다. [[김철수]]가 나타난다. ##

김철수
@@ 박영희는 어디 있어? @@

₩₩ 모든 것은 그날부터 시작되었다. ₩₩

// 이 메모는 최종 출력에서 제외됩니다.
```

`[[김철수]]`는 인물 최초 등록이고, 이후 `김철수`를 일반 텍스트로 써도 인식합니다.
`[[장소:서울역]]`은 장소 등록입니다. `@@`는 대사, `##`는 행동/묘사, `₩₩`는 나레이션, `#`은 장면 제목입니다.

## 단축키
| 키 | 동작 |
|---|---|
| Ctrl+N / Ctrl+O | 새 작품 / 프로젝트 열기 |
| Ctrl+S | 저장 |
| Ctrl+Z / Ctrl+U | Undo / Redo |
| Ctrl+T | 작품 제목 편집 |
| Ctrl+Shift+O | 선택한 이름을 오브젝트 등록 |
| Ctrl+G | 선택한 오브젝트 다음 등장 위치로 이동 |
| Ctrl+Shift+P | 화면 미리보기 전환 |
| Ctrl+Shift+H | 이전 저장본 복원 |
| F1 | 인앱 사용법 보기 |

## 데이터와 내보내기
원고는 `script/main.txt` (UTF-8)이며 메타데이터와 저장 기록은 `project.sqlite`에 있습니다.
`File > Export`에서 DOCX, PDF, 실험적 HWPX를 생성할 수 있습니다.
**현재 PDF는 한글 표시를 위해 페이지 래스터 방식입니다. 텍스트 검색/복사 불가.**
**HWPX는 구조 검증 단계이며 실제 한컴오피스 호환성은 미확인.**
macOS Swift 빌드는 Windows v0.2.0 UI 기능과 아직 완전 동등하지 않습니다.
